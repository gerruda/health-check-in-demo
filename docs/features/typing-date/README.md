# Фича: typing-индикатор и дата в формате ДД.ММ.ГГГГ

**Ветка:** `feat/typing-date` · **Статус:** готово к PR (проверки зелёные) · **Дата:** 2026-11-12
**Связанные пункты ТЗ:** FR-3.8 (UX/тон), FR-6.8.5 (ответ на скриншоты), NFR-4.

## 1. Зачем

Пользователь отправляет боту скриншот: vision-обработка занимает секунды
(холодная загрузка — десятки секунд), и без индикатора бот «молчит» — непонятно,
работает он или упал. Нужен Telegram-статус **«печатает»** на всё время работы.

Вторая правка: в ответах бота дата должна быть в региональном формате
**ДД.ММ.ГГГГ** (сначала число, месяц, год), а не ISO `YYYY-MM-DD`.
Имена файлов в файловой БЗ остаются ISO (`YYYY-MM-DD.md`) — это контракт данных.

## 2. Acceptance criteria

| # | Критерий | Проверка |
|---|---|---|
| AC1 | `typing.Start`: первый action сразу, повтор каждые ≤4 с, пока обработка не завершена; `stop()`/отмена ctx останавливают | `internal/typing/typing_test.go` |
| AC2 | Ошибки/недоступность `sendChatAction` не влияют на обработку (только debug/игнор) | код |
| AC3 | LLM-чат: typing отправляется до ответа модели | `router/typing_test.go` |
| AC4 | Приём фото/текста (async): typing идёт всё время распознавания | `intake/typing_test.go` |
| AC5 | `FormatReply` показывает дату `ДД.ММ.ГГГГ` («11.11.2026»), ISO в файлах не меняется | `TestFormatReplyDateRU` |
| AC6 | `make check`/`-race` зелёные; PR | CI |

## 3. Решения

- Пакет `internal/typing`: `Start(ctx, chatID, send, opts...)` — первый вызов
  синхронно (сразу виден статус), затем тикер 4 с (Telegram держит статус ~5 с).
- `router.WithTyping` — для LLM-чата; `intake.WithTyping` — для фото/текста
  (обработка асинхронная, поэтому индикатор живёт в сервисе).
- Ошибки action игнорируются: индикатор — UX, не критичный путь (NFR-2).
- Дата: человекочитаемый формат только в чате; JSON/CLI и имена файлов — ISO.
- Не критичные для сохранения поля (температура, цель нагрузки, усталость)
  остаются в `intake.Extracted` для анализа/ответа, но не пишутся в чек-ин;
  сохраняются критичные: сон, HRV, пульс покоя (плюс настроение/алкоголь и т.п.).
