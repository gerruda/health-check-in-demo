# Фича: M2 — HRV_7-тренд и ответы тренера в чат (check-in, питание)

**Ветка:** `feat/m2-coach` (стек от `feat/m2-analysis`, база PR — ветка анализа) ·
**Статус:** готово к PR (стек; проверки зелёные) · **Дата:** 2026-11-12
**Связанные пункты ТЗ:** FR-3.1 (ответ на чек-ин ≤10 строк), FR-3.5 (ответ на питание),
FR-3.7 (тренд), контракт §6.1/§6.3, §13.

## 1. Зачем

Дать боту **формат ответа** из контракта, опираясь на уже готовый анализ
(`internal/analysis`): зона готовности и цели питания. Это последний чистый слой
перед интеграцией в Telegram — ответы собираются функциями, их легко проверить
golden/unit-тестами и потом отдать в router.

## 2. Acceptance criteria

| # | Критерий | Проверка |
|---|---|---|
| AC1 | `TrendHRV(values)` → среднее, направление ↑/→/↓, min/max, count; пустой ряд → «нет данных» | `hrv_test.go` |
| AC2 | Направление считается от среднего с шумовым порогом ±1 мс (один день не считается трендом) | `hrv_test.go` |
| AC3 | `CheckinReply` ≤10 строк: зона 🟢/🟡/🔴 + причина; HRV_7 (среднее, направление, 🟢/🟡/🔴 за 7 дней); план на день (по зоне/из плана); фокус; флаг при аномалии | `coach_test.go` |
| AC4 | План по умолчанию: 🟢 «по плану», 🟡 «одна лёгкая, сдвоенные убрать», 🔴 «отдых/прогулка»; заметки зоны (колени/МЦ) попадают в ответ | `coach_test.go` |
| AC5 | `NutritionReply` ≤8 строк: калории/Б/Ж/У vs цель, флаги ✅/⚠️, 7-дневные средние (если есть), алкоголь (если есть), одна правка | `coach_test.go` |
| AC6 | Нет данных → честное «нет данных», не паника; тон на «ты», без стыда | tests |
| AC7 | `make check`/`-race` зелёные; спека/README; PR (стек от m2-analysis) | CI |

## 3. Решения

- Ответы — **чистые строки** без Telegram: router просто отправит их (`reply`).
- Лимиты строк контракта проверяются в тестах (`strings.Count(reply,"\n")+1`).
- Направление HRV: среднее по всем значениям, последнее сравнивается с
  `avg ± 1 мс`; меньше 2 значений → `flat` (тренд не определить).
- Счётчики зон за 7 дней передаются снаружи (анализ истории сделает интеграция на
  m1-store reader); если нет данных — строка опускается.
- «Фокус дня» и «флаг» — опциональны; пустые — опускаются, но лимит строк соблюдается.
- Эмодзи зоны берётся из `Zone.Emoji()`.

## 4. Матрица тестов

| Тест | Что проверяет |
|---|---|
| `TestTrendHRVEmpty` | нет значений → count 0, направление flat |
| `TestTrendHRVUp/Down/Flat` | направление по последнему vs среднее; шум ±1 |
| `TestTrendHRVStats` | среднее, min/max, count |
| `TestCheckinReplyGreen` | 🟢, HRV_7, план по умолчанию, ≤10 строк |
| `TestCheckinReplyYellowNotes` | 🟡, заметки колени/МЦ, план «одна лёгкая» |
| `TestCheckinReplyRedFlag` | 🔴, флаг, план «отдых» |
| `TestCheckinReplyNoTrend` | «нет данных» про HRV_7 |
| `TestNutritionReplyInTargets` | сводка, ✅, без «правка:» |
| `TestNutritionReplyOutOfRange` | ⚠️ и одна «правка:» |
| `TestNutritionReplyLines` | ≤8 строк |

## 5. Что НЕ входит

- Отправка в Telegram и обработка команд (`/status`, `/week`) — интеграционный PR.
- 7-дневные средние из файлов (reader m1-store) — передаются в input.
- Прогрессия тренировок/формат тренировки — следующим инкрементом.
