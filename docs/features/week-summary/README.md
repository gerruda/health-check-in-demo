# Фича: `/week` — сводка недели (FR-5)

**Ветка:** `feat/week-summary` · **Статус:** готово к PR · **Дата:** 2026-11-12
**Связанные пункты ТЗ:** FR-5 (`/week`), FR-3 (анализ), FR-8 (голос «Ритм»).

## 1. Зачем

Нужен обзор последних 7 дней одним сообщением: HRV/зоны, сон, пульс,
питание против целей, тренировки и вес. Звучит «Ритм»: без оценок и давления.

## 2. Что показывает (за последние 7 дней, включая сегодня)

```text
🌿 Неделя атлета: 06.11.2026–12.11.2026
HRV: 32.0 мс в среднем · ↑ рост · 🟢3 / 🟡1 / 🔴0
Сон: 6:53 в среднем
Пульс покоя: 59 в среднем (макс 60)

Питание (1 дн.): 2300 ккал · Б 130 · Ж 82 · У 210
Цели: ккал 2300 · Б 108–135 · Ж 80–90 · У 200–250

Тренировки: 2 (выполнено 1, пропуск 1) · 55 мин · силовая A 1
Вес: 102.4 кг (↓ 0.6 кг за неделю)
Ориентир: сегодня по плану
```

- **HRV**: среднее за окно, направление (↑/→/↓), счётчики зон по дням (пороги — из настроек).
- **Сон**: среднее ЧЧ:ММ и число ночей ниже жёлтого порога.
- **Пульс**: среднее и максимум.
- **Питание**: средние по дням, где есть 4 числа; «(N дн.)» — сколько дней с данными.
- **Тренировки**: всего, выполнено/пропуск, суммарная длительность, типы.
- **Вес**: последний за неделю и изменение от первого замера в окне.
- **Ориентир**: `PlanForZone` по последнему дню; нет данных — честное «нет данных».

## 5. Что НЕ входит

- Календарная неделя (пн–вс) — сейчас скользящие 7 дней; при желании переключим.
- Средние за 7 дней только по дням с данными; пропуски не экстраполируются.
- Разбор тренировки vs предыдущей и следующая тренировка (FR-3.3) — следующий инкремент.
