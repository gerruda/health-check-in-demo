# Фича: разбор тренировки и следующая тренировка (FR-3.3/FR-3.4, U8–U9)

**Ветка:** `feat/training-analysis` · **Статус:** готово к PR · **Дата:** 2026-11-12
**Связанные пункты ТЗ:** FR-3.3 (разбор), FR-3.4 (прогрессия), U8/U9.

## 1. Зачем

Бот принимал тренировку и отвечал только «Отметил, сохранено». Нужен разбор:
объём/RPE vs предыдущая, что прогрессировало, **следующая тренировка с числами**
и замены при боли.

## 2. Поведение

После `/training`/текстового отчёта:

```text
🌿 Отметил тренировку: силовая A 55 мин RPE 8
Объём: 3480 (было 3200, +9%).
Следующая:
• присед · 62.5 кг · 5×5 — +2.5 кг
• жим гантелей · 16 кг · 4×10 — +2 кг
Плечо 2/10: без классических отжиманий в отказ — жим гантелей/эспандер.
Сохранено: данные_пользователя/тренировки/…md
```

Правила прогрессии (FR-3.4):
- RPE ≤5 и есть вес → штанга +2.5 кг, гантели +2 кг; без веса — +1 повтор;
- RPE 6–8 → вес/повторы закрепляем;
- RPE растёт 2 сессии (последняя ≥8) **и** зона жёлтая/красная → **deload**
  (−25% объёма, вес держим); красная зона — deload сразу;
- сравнение объёма: вес×подходы×повторы (без веса — подходы×повторы);
- боль: плечо → без классических отжиманий в отказ; колени → без глубоких
  приседов/выпадов/прыжков.
