# Фича: M1 — файловое хранилище (пути, атомарная запись, merge)

**Ветка:** `feat/m1-store` · **Статус:** готово к PR (проверки зелёные) · **Дата:** 2026-11-12
**Связанные пункты ТЗ:** FR-2 (сохранение в файловую БЗ), §5 (`store/`, `nlu/models`), §6 (модель данных), §13 (U10, I2).

## 1. Зачем

После LLM-чата и приёма данных (photo-intake) нужен слой, который **сохраняет**
данные в существующую файловую БЗ проекта по контракту
`протоколы/прием_чекинов_и_отчетов.md`: `данные_пользователя/` или `данные_жены/`,
по шаблонам и именам файлов.

Инкремент намеренно **не трогает** `app/router/config` (их меняет открытый PR
photo-intake) — добавляет независимые пакеты `nlu` (модель) и `store` (пути,
writer, reader). Интеграция в диалог — следующим PR после мержа.

## 3. Архитектура и решения

```
internal/nlu/models.go     структуры домена (ТЗ §6), без сети/ФС
internal/store/paths.go    правила путей/имён для двух людей + валидация
internal/store/writer.go   атомарная запись, merge секций по заголовкам
internal/store/reader.go   даты чек-инов, последняя дата, чтение файла
```

- **Атомарность:** временный файл в том же каталоге (`os.CreateTemp`), `Close`,
  `os.Rename`; при ошибке исходный файл не трогается.
- **Merge:** markdown-документ = заголовок + секции `## …`. Новые строки
  дописываются в существующую секцию, только если их там ещё нет; старые строки
  сохраняются; при изменениях ставится маркер `<!-- обновлено: … -->`; при
  отсутствии изменений файл не перезаписывается (идемпотентность).
- **Дата:** в API — `time.Time`, в файле — `YYYY-MM-DD`; источник даты —
  парсер/интейк (M1 интеграция); writer валидирует.
- **Тренировки:** типы атлета — `fitboxing|sila-A|sila-B|ulichnaya|vosstanovlenie`;
  жены — `silovaya|kardio|progulka` или `MC<N>_<тип>`; прочие — ошибка.
- **Питание:** отдельного каталога нет (FR-2.3) — секция в чек-ине за дату
  питания; при интеграции с чатом дата берётся из распознанного «вчера».
- **Reader** пока минимальный (список/последняя дата/сырое чтение); парсинг
  HRV_7 и трендов — M2, он будет читать те же файлы.
