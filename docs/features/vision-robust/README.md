# Фича: устойчивое распознавание скриншотов часов/фитнес-приложений

**Ветка:** `feat/vision-robust` · **Статус:** готово к PR · **Дата:** 2026-11-12
**Связанные пункты ТЗ:** FR-6.8 (скриншоты), FR-2.2 (тренировки), FR-2.7 (пропуск), FR-8 (голос).

## 1. Что сломалось (воспроизведено на реальных скриншотах жены)

Модель (qwen2.5vl:3b) на экране сна вернула `sleep:"70 уд/м"`, `hrv_ms:0`;
парсер **падал на первом же неверном поле** и отбрасывал весь скриншот.
Экран тренировки не был описан в схеме вообще — `training` отсутствовал.
Один большой промпт с вложенной схемой на 3B-модели давал «фантазии»:
31:15 → 45 мин, пульс 70 → сон, 60/100 → load_goal, SpO2/Body Battery из воздуха.

## 2. Решение: двухфазный vision + код

```
скриншот
  → 1) классификация типа: sleep_quality | sleep_metrics | workout | nutrition | other
  → 2) специализированный промпт/схема:
        sleep_quality — только длительность + баллы;
        sleep_metrics — HRV, пульс покоя, ночная ЧСС, SpO2, дыхание, Body Battery;
        workout — OCR всего экрана → детерминированный парсер
                  (Общее время, Средняя ЧСС, Калории, таблица Подход/Повтор/Вес);
        nutrition — ккал/БЖУ/приёмы;
  → толерантная нормализация: мусорные/вне диапазонов поля отбрасываются,
    а не ломают весь разбор; пустой результат → «пришли другой скриншот»
  → чек-ин и/или тренировка сохраняются по шаблону; даты у каждого свои.
```

Почему OCR для тренировки: 3B-модель путает числа в структуре, но **текст экрана
читает точно** («Общее время 31:15», «92 уд/м», «4», «--»); код разбирает это
надёжно. Для сна наоборот — специализированные поля дают 8 ч 9 м / 34 мс / 65.

Даты: «Сегодня»/«Вчера»/«11 нояб.» — код; месяцы с сокращениями («нояб», «окт»…).
Тренировка со скрина сохраняется в `данные_*/тренировки/YYYY-MM-DD_<тип>.md`
(Итог/Упражнения/Кардио), чек-ин — отдельно за свою дату.

## 6. Ограничения

- 3B-модель всё ещё может ошибаться; специализация + OCR + диапазоны снижают риск.
- Классификатор простой; при неоднозначном экране fallback: quality → metrics →
  generic sleep.
- Для совершенно новых приложений добавляем синонимы в промпты (список расширяемый).
- Внешний vision API — только если настроен; по умолчанию локальный Ollama.
