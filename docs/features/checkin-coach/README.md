# Фича: коуч-ответ на чек-ин (FR-3.1)

**Ветка:** `feat/checkin-coach` · **Статус:** готово к PR (проверки зелёные) · **Дата:** 2026-11-12
**Связанные пункты ТЗ:** FR-3.1 (ответ на чек-ин), FR-3.2 (зоны), FR-3.7 (HRV_7), FR-8 (голос «Ритм»).

## 1. Зачем

До этого после чек-ина бот присылал только «Отметил данные… Сохранено…» —
без зоны, тренда и ориентира на день. Теперь после успешного сохранения
чек-ина приходит ответ по контракту §6.1: зона + причина, HRV_7, ориентир.

## 2. Acceptance criteria

| # | Критерий | Проверка |
|---|---|---|
| AC1 | После сохранения чек-ина `intake.Coach` собирает ответ; `intake` не знает про `store`/`analysis` | `intake/coach_test.go` |
| AC2 | Ответ: «🌿 Доброе утро», зона 🟢/🟡/🔴 + причина, HRV_7 (среднее/направление/счётчики), «Ориентир», «Сохранено: путь» | demo + tests |
| AC3 | Зона считается по сохранённым данным и настройкам (база/пороги/margins), а не по сырому сообщению | `app` test |
| AC4 | Для зелёной зоны в ориентир попадает план пользователя (`PlannedTraining`); для жёлтой/красной — дефолт зоны | test |
| AC5 | Ошибка коуча/нет данных → прежняя сводка + сохранение (без падения); питание-only не вызывает коуча | тесты |
| AC6 | `make check`/`-race`/`govulncheck`; спека/README/отчёт; PR | CI |

## 3. Как устроено

```
intake.Service.process* → save() → paths
  → buildReply: есть coach && сохранён чек-ин && paths>0
      → coach.CheckinReply(chatID, extracted) (app)
          → settings.Load + reader.CheckinValues(14)
          → база (ручная/7-дневное среднее), пороги из настроек
          → analysis.Evaluate + TrendHRV + ZoneCounts
          → analysis.CheckinReply (голос «Ритм»)
      → + «Сохранено: путь»
  → иначе FormatReply (старое поведение)
```

- `intake.Coach` — интерфейс в `intake`; реализация — `app.commandHandlers.CheckinReply`.
- Дата берётся из `extracted.Date` (задним числом), ищется соответствующий чек-ин;
  иначе — последний.
- Ошибки чтения/настроек приводят к fallback-сводке, запись уже сделана.

## 5. Что НЕ входит

- Фокус дня и флаги аномалий в коуч-ответе — следующим инкрементом (FR-3.1).
- Заметки жены (колени/МЦ) из файла — после расширения reader.
- `/week` — отдельная задача.
