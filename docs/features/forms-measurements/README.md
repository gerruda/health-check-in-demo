# Фича: FSM-формы, замеры и воскресный разбор (M4)

**Ветка:** `feat/kb-consultant-forms` · **Статус:** готово к PR · **Дата:** 2026-11-12
**Связанные пункты ТЗ:** FR-2.4, FR-3.7, FR-5, контракт приёма.

## 1. Принцип: свободный ввод остаётся основным

- Обычный текст/фото работают как раньше: авто-детект чек-ина/тренировки/чата.
- Формы запускаются только явно: `/checkin`, `/training` (без текста), `/food`,
  `/measure`. Пока форма активна, текст — ответ на текущий шаг; `/cancel` —
  выход (форма или pending-уточнение).
- После завершения форма пишет через тот же `Saver`/intake, что и свободный
  текст: одинаковые шаблоны, merge и coach-ответы.
- Таймаут формы — 15 минут; состояние in-memory (SQLite-персистентность —
  следующий шаг).

## 2. Формы

| Форма | Поля |
|---|---|
| `/checkin` | сон (7:30 / 7.5), HRV, пульс покоя, настроение, алкоголь, план |
| `/training` | тип, упражнения текстом, RPE, длительность, средний пульс |
| `/food` | ккал, Б, Ж, У; после сохранения — NutritionCoach (цели, 7 дней, одна правка) |
| `/measure` | вес, %жира, %мышц, висцеральный, вода, талия, лента (5 чисел или «-») |

## 3. Замеры и разбор

- `Writer.WriteMeasurement` / `Reader.Measurements`:
  `данные_<кто>/замеры/YYYY-MM-DD.md`, merge секций, Picooc + лента.
- `/review` — воскресный разбор: текущие замеры, Δ к прошлому, HRV/сон за 14 дней,
  1–3 действия; без оценок и вины.
- Автоматическое воскресное напоминание — backlog (следующий шаг).
