# Фича: приём тренировок текстом + чистка `/status`

**Ветка:** `feat/training-intake` · **Статус:** готово к PR · **Дата:** 2026-11-12
**Связанные пункты ТЗ:** FR-1.1 (свободная форма), FR-2.2/2.7 (файлы тренировок/пропуск), FR-3.3 (разбор — частично), FR-5 (`/training`, `/status`), FR-8 (голос).

## 1. Зачем

Бот принимал чек-ины и питание, но **не принимал тренировки** — при том что
`/week` и прогрессия без них бессмысленны. Теперь можно прислать отчёт текстом
(или `/training ...`) и получить сохранение в
`данные_*/тренировки/YYYY-MM-DD_<тип>.md`.

Заодно `/status` стал коуч-ответом: добавлен «Ориентир» по зоне, а упоминания
LLM/vision убраны — модели достаточно в `/settings`.

## 2. Acceptance criteria

| # | Критерий | Проверка |
|---|---|---|
| AC1 | `LooksLikeTraining`: распознаёт отчёт с упражнениями/«сделал»/«пропуск»/RPE; не путает с чек-ином/вопросом | `training_test.go` |
| AC2 | `ParseTraining`: упражнения (вес/подходы/повторы/RPE), длительность, средний пульс, RPE сессии, самочувствие, боль, пропуск, типы атлета/жены (включая `MC<N>_...`) | `training_test.go` |
| AC3 | Маршрутизация: текст-тренировка уходит в intake до чек-ина; `/training` без аргументов — подсказка | `router/training_test.go` |
| AC4 | Сохранение через `Saver.SaveTraining` → `store.Writer`; пропуск → «не сделано»; ответ в голосе «Ритма» + путь | service tests + реальный store |
| AC5 | `/status`: «Ориентир», без LLM/Vision; модели — только в `/settings` | app test |
| AC6 | `make check`/`-race`/`govulncheck`; спека/README/отчёт; PR | CI |

## 3. Поддерживаемые форматы (примеры)

```text
силовая A: присед 60x5x5, жим гантелей 14 кг 4×10 RPE 7, RPE 8, 55 мин
Вчера была тренировка. Уличная. Суставная разминка затем подтягивания
узким хватом 3 раза, отжимания на брусьях 10 раз, зашагивания на платформу
с эспандером 15 раз на каждую ногу. Все упражнения по 3 подхода. RPE 8.
Затем кардио подъем по лестнице на 32 этаж.
не сделал тренировку, колено 5/10
кардио 30 мин, средний пульс 130
MC2 силовая: присед 40x3x10, самочувствие: тяжело
```

- «60x5x5» → 60 кг, 5 повторов, 5 подходов; «14 кг 4×10» → 14 кг, 4×10.
- «40x8» → 40 кг × 8; «4x10» без веса → 4 подхода × 10.
- **Естественный язык**: «3 раза», «10 повторений», «15 раз на каждую ногу»;
  «Все упражнения по 3 подхода» → общие подходы; «вчера» → дата; «Уличная» →
  тип; «кардио/лестница/этаж» → секция кардио, а не упражнение; «разминка» —
  упражнение с пометкой.
- Типы атлета: `fitboxing|sila-A|sila-B|ulichnaya|vosstanovlenie`; жены:
  `silovaya|kardio|progulka|MC<N>_...` (маппинг при сохранении).
- Пропуск (`не сделал`, `пропуск`) → файл с «не сделано» (FR-2.7).

## 4. Что НЕ входит

- Разбор тренировки vs предыдущей и **следующая тренировка с числами** (FR-3.3) —
  следующий инкремент, после прогрессии U8–U9.
- FSM `/training` по шагам (M4); сейчас свободный текст/команда.
- `/week` — после тренировок и парсинга истории.
