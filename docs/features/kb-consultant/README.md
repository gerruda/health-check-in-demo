# Фича: поиск по базе знаний и консультант (M3)

**Ветка:** `feat/kb-consultant-forms` · **Статус:** готово к PR · **Дата:** 2026-11-12
**Связанные пункты ТЗ:** FR-3.6, FR-4 (переработан), FR-8.

## 1. Зачем

База знаний проекта уже ведётся отдельно (`база_знаний/`, ~318 чанков).
Боту не нужно тащить статьи из интернета — нужно **искать ответы в локальной
базе** и отвечать как консультант по фитнесу/ЗОЖ.

## 2. Что сделано

- `internal/kb` — гибридный in-memory индекс (BM25 + embeddings):
  - embeddings через Ollama `/api/embed` (`nomic-embed-text`), батчи,
    дисковый кэш `DATA_ROOT/.healthbot/kb_embeddings.json`;
  - при сбое embeddings — лексический fallback;
  - чанки по `#`/`##`/`###`, категории (`исследования`, `методики`, `жена`,
    `протоколы`), PMID из текста;
  - русские синонимы/нормализация (HRV/ВСР, пульс/ЧСС, протеин/белок,
    жиросжигание/похудение, колени, плечо, MASLD и т.д.);
  - `Search(query, person, limit)`: top-K, сниппеты, boost `жена/` для wife.
- `internal/tools/search_knowledge` — инструмент для LLM (точечные запросы).
- Гибридный `SearchHybrid`: BM25 + cosine, top-K; `search_knowledge`/`/ask`
  используют его.
- **Детерминированный префетч**: `llm.Agent.WithContextProvider` кладёт top-4
  фрагмента в системный промпт до вызова модели; инструмент поиска при этом
  убирается, чтобы 3B не делала лишний tool-call. `/ask` и свободный чат
  используют один агент.
- Санитайзер ответа: выдуманные DOI/URL/PMID вычищаются; PMID разрешён только
  из найденного контекста; в конце добавляются реальные источники (файл+PMID).
- `/ask <вопрос>` — явный вход; свободный вопрос в чате тоже получает контекст.
- Промпт «Ритма»: не выдумывать источники, сначала ответ → факты → применение →
  оговорка; «в базе знаний пока нет» без ссылок; red flags → врач.

## 3. Acceptance

| # | Критерий | Проверка |
|---|---|---|
| AC1 | Поиск находит файл по русскому синониму и отдаёт PMID | `TestSearchFindsRussianSynonymsAndPMID` |
| AC2 | Нет результата — честный текст, не галлюцинация | `TestSearchNoMatch`, tool test |
| AC3 | Контекст попадает в промпт до вызова модели | `TestAskInjectsKnowledgeContextBeforeLLM` |
| AC4 | Выдуманные PMID/DOI/ссылки удаляются | `sanitizeKnowledgeAnswer` + tests |
| AC5 | `/ask` в роутере | router tests |
| AC6 | `make check`/`-race`/`govulncheck`; спека/README/отчёт; PR | CI |

## 4. Границы

- Заполнение базы статьями (fetch/PubMed/очередь) — **не M3**, отдельный backlog.
- Векторный поиск реализован (Ollama embeddings + кэш); внешняя векторная БД
  не нужна при текущем объёме базы.
- Индекс строится при старте; правки базы подхватываются после рестарта.
